UI review: Ship it for local review
Date: 2026-10-22

Scope: React + TypeScript frontend in web/src, Vite build, pnpm data preparation.
The original Python analysis/export is independent of this app.

| Before | After | Why |
| --- | --- | --- |
| Long generated report | Play browser, replay workspace, receiver inspector | Switch plays without losing the study context |
| Monolithic DOM script | Typed React components and a pure replay module | Separate playback, rendering and navigation |
| Embedded tracking for every play | Index plus per-cue JSON requests | Load only the tracking needed for the selected receiver |
| Mobile controls overlapped by navigation | Library opens from the persistent header | Keep playback controls reachable |
| Scaled-down chart labels | Responsive SVG coordinate space | Keep labels legible on narrow screens |
| Comparison-card overflow | Constrained grid columns and wrapping labels | Keep both moments readable at 320px |
